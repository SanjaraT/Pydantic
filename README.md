--> Overview

This repository contains simple, educational examples showing how to use Pydantic (a Python library for data validation and settings management using type hints) .

Each script in this repo demonstrates one of the core capabilities of Pydantic, such as field validation, model validation, nested models, and computed fields. The goal is to learn how Pydantic helps you write cleaner, type-safe Python code that automatically checks and parses data.

--> Contents

pydantic1.py – Basic BaseModel usage and validation

field_validator.py – Field-level validation with custom rules

model_validator.py – Model-level validation involving multiple fields

nested_model.py – Nested Pydantic models

computed_fields.py – Computed fields derived from other attributes

--> Purpose

This repository is for learning and practice and serves as a reference for using Pydantic in real-world Python and API projects.
